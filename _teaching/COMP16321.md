COMP16321: Introduction to Programming 1 (Semester A, 2025/26 Academic Year)

Learning outcomes:

1. Evaluate the quality of code (correctness, maintainability, efficiency)
2. Estimate the development time needed to implement a solution to a problem
3. Explain what a given (simple) program does
4. Design programs to solve given (simple) problems
5. Explain basic programming constructs and describe their manifestation in different programming languages
6. Identify appropriate programming resources (tools, libraries) needed to implement a solution to a problem
7. Implement maintainable solutions to problems using appropriate development tools
